Why structure matters

Semantic elements describe the purpose of page content. A clear structure helps people using assistive technology and helps search engines understand the page.

Good page practices

Use clear headings

This page uses one main heading followed by section headings and a smaller heading within a section.

Write useful link and image text

Navigation links describe their destinations, and the image has alternative text describing its content.

About this example

The page has a meaningful title, description, viewport, and author metadata. Metadata can describe a page, but meta keywords alone do not improve Google rankings.
