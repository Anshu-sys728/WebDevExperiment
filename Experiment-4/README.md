# Experiment 4: SEO and Accessibility

## Aim

Improve a webpage's SEO and accessibility using semantic HTML, a clear heading structure, and metadata.

## Tools and technologies used

- HTML5
- CSS3
- A remotely hosted example image

## Basic description of the implementation

The page uses `header`, `nav`, `main`, `section`, and `footer` elements, plus a clear h1-h2-h3 heading hierarchy. It includes a meaningful title, description, viewport, and author metadata, descriptive navigation links, and alt text for its image.

## Main concepts used

- Semantic page landmarks
- Heading hierarchy
- Page title and descriptive metadata
- Descriptive link text and image alternative text
- Separate stylesheet

Metadata can help describe a page, but meta keywords alone do not improve Google rankings.

## Steps to run the project

1. Open `index.html` in a web browser.
2. Keep an internet connection available to load the example image.
3. Use the navigation links to jump to the matching sections.

## Expected output

A readable page with three clearly linked sections, an accessible navigation label, a descriptive image alternative, and semantic landmarks.
