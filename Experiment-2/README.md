# Experiment 2: Personal Portfolio Website

## Aim

Develop a personal portfolio webpage with navigation, an about section, project cards, and a contact form.

## Tools and technologies used

- HTML5
- CSS3
- Bootstrap 5 CSS and JavaScript from the official jsDelivr CDN

## Basic description of the implementation

The page contains a responsive Bootstrap navigation bar, a short introduction, an about section, three project cards, and a contact form with name, email, and message fields. The form is only a visual example: its preview button does not submit, and it has no backend and does not send or store messages.

## Main concepts used

- Semantic HTML sections and navigation links
- Bootstrap responsive grid and form components
- Separate CSS file for page-specific styling
- Required form fields and labels

## Steps to run the project

1. Open `index.html` in a web browser.
2. Keep an internet connection available so Bootstrap can load from its CDN.
3. Use the navigation links to move between the page sections.

## Expected output

A responsive personal portfolio with a collapsible navigation menu, three project cards, and a labelled sample contact form is displayed.
