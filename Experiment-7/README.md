# Experiment 7: Notes App Using React

## Aim

Create a simple React app to add, view, edit, and delete notes.

## Tools and technologies used

- HTML5
- CSS3
- React 18
- Browser local storage

## Basic description of the implementation

The page has a form for note titles and content, followed by a list of saved notes. Users can add a note, edit it in the form, or delete it. Notes are saved in the browser so they are still there after a refresh.

## Main concepts used

- React state with `useState`
- React effects with `useEffect`
- Form input and button event handlers
- Displaying a list with `map`
- Saving data in local storage

## Steps to run the project

1. Open `index.html` in a browser with an internet connection.
2. React and Babel load from CDNs, so no installation is needed.
3. Use the form to add a note. Select **Edit** to change it or **Delete** to remove it.

## Expected output

A simple page with a note form and a list of notes.
